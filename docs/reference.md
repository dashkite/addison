# Reference

## Value

### @from
$@from: data \to value$

Returns a new Value instance with the provided data.

### data
$data \to any$

The underlying data associated with the value.

## Atomic

Represents a model for a single resource.

### @make
$@make: locator \to atomic$

Creates a new Atomic model instance for the provided locator.

### @resolve
$@resolve: specifier \dashrightarrow atomic$

Creates and resolves an Atomic model instance using the provided specifier.

### resolve
$resolve: specifier \dashrightarrow atomic$

Resolves the model's resource using the provided specifier.

### get
$get: \to \emptyset$

Triggers a fetch of the resource state. Returns a promise that resolves when the command is processed.

### put
$put: mutator \dashrightarrow \emptyset$

Updates the resource state using the provided mutator function. Returns a promise that resolves when the mutation is complete.

### delete
$delete: \to \emptyset$

Triggers a deletion of the resource. Returns a promise that resolves when the command is processed.

### post
$post: builder \dashrightarrow \emptyset$

Posts data generated by the `builder` function to the resource. The `builder` receives the current model value. Returns a promise that resolves when the post is complete.

## Composite

Represents a model that aggregates multiple resources.

### @make
$@make: locators \to composite$

Creates a new Composite model instance with the specified map of locators.

### @resolve
$@resolve: specifier \dashrightarrow composite$

Creates and resolves a Composite model instance using the provided specifier.

### resolve
$resolve: specifier \dashrightarrow composite$

Resolves all underlying resources using the provided specifier.

### get
$get: \to \emptyset$

Triggers a fetch for all underlying resources. Returns a promise.

### put
$put: mutator \dashrightarrow \emptyset$

Updates the aggregate state using the provided mutator function. Returns a promise.

### delete
$delete: \to \emptyset$

Triggers a deletion of all underlying resources. Returns a promise.

### post
$post: builder \dashrightarrow \emptyset$

Posts data generated by the `builder` function to the underlying resources. The `builder` receives the current aggregate value and should return a map of data for specific sub-resources. Returns a promise.
